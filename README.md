# 🪐 AdPlanet
> **AI와 함께 당신의 브랜드를 빛나게 할 올인원 AI 크리에이티브 스튜디오**


<br>

## 🚀 개요
**AdPlanet**은 전문 디자이너 고용에 어려움을 겪는 **초기 스타트업 및 개인 창작자**를 위한 서비스입니다.

브랜드 로고부터 광고 포스터, 디지털 워터마크까지 하나의 워크플로우로 제공하는 통합 디자인 플랫폼입니다.<br>
비용과 시간의 제약 없이 누구나 자신만의 브랜드를 만들고 성장시킬 수 있도록, AI 기술을 활용하여 브랜딩 자산을 쉽고 빠르게 제작할 수 있는 환경을 제공합니다. <br>

<br>

## 🌟 주요 기능

### 🎨 로고
- **원클릭 스타일 적용**: 추천 스타일을 클릭 후 해당 스타일 반영
- **프롬프트 기반 생성**: 간단한 프롬프트 입력으로도 손쉽게 로고 생성 가능
- **Stable Diffusion 기반 모델** : 고품질 이미지 출력 및 확장성 보장
- **파일 포맷 변환** : 완성된 로고를 PNG, JPG, SVG 등 필요한 포맷으로 다운로드
- **CI 가이드라인** : 로고의 색상 코드와 사용 규정이 담긴 브랜드 CI 가이드라인 자동 생성

### 🖼️ 포스터
- **제품·모델 이미지 반영** : 업로드한 실제 이미지를 포스터에 자동 적용
- **구도·포즈 제어 (ControlNet)** : Reference 이미지에서 OpenPose 추출 → 구도·포즈 반영
- **포스터 수정** : Qwen-Image-Edit 모델로 생성된 포스터를 부분 수정
- **광고 문구 자동 생성** : 프롬프트 및 제품 정보 기반으로 포스터에 어울리는 문구 생성

### 🔐 디지털 워터마크
- **비가시성 워터마크** : 생성자 정보를 이미지에 보이지 않게 삽입
- **Steganography** : 최하위 비트에 정보를 은닉하는 LSB 기법으로 이미지 품질 저하 최소화
- **워터마크 검증** : 무단 도용 방지 및 추적

### 👤 사용자 기능
- **SSAFY 계정 연동** : 별도의 회원가입 없이 SSAFY 계정으로 간편하게 로그인
- **마이페이지** : 내가 생성한 모든 디자인 자산을 한눈에 확인하고 관리
