## AI Server

* **Python:** 3.12.11
* **패키지:** `AI/requirements.txt`
* **실행 엔트리:** `AI/main.py`
* **ngrok:** `외부 네트워크에서 로컬환경으로 접속할 수 있게 해주는 터널링`

> 설치/실행

```bash
cd AI
pip install -r requirements.txt
uvicorn main:app --reload
ngrok http 8000
```

> 확인 명령어

```bash
python --version
pip list | head
```

## 환경 변수

### Database Configuration
- DB_HOST=디비 호스트
- DB_PORT=디비 포트
- DB_NAME=디비 이름
- DB_USERNAME=디비 유저 이름
- DB_PASSWORD=디비 유저 패스워드

### SSH Tunnel Configuration
- SSH_HOST=터널링 호스트
- SSH_USERNAME=터널링 유저 이름
- SSH_PRIVATE_KEY_LOCAL_PATH=pem키 경로
- SSH_PRIVATE_KEY_PROD_PATH=pem키 경로

### RDS Configuration
- RDS_HOST=RDS 호스트
- RDS_PORT=RDS 포트

### JWT Configuration
- JWT_SECRET=JWT 시크릿 키
- JWT_ACCESS_TOKEN_EXPIRATION=AT 만료 시간
- JWT_REFRESH_TOKEN_EXPIRATION=RT 만료 시간

### Redis Configuration
- REDIS_HOST=Redis 호스트
- REDIS_PORT=Redis 포트
- REDIS_LOCAL_PORT=포워딩을 위한 로컬 포트

### SSAFY OAuth Configuration
- CLIENT_ID=SSAFY OAuth ID
- CLIENT_SECRET=SSAFY OAuth Secret
- REDIRECT_URI=Redirect URI

### S3
- AWS_ACCESS_KEY_ID=S3 Key Id
- AWS_SECRET_ACCESS_KEY=S3 Secret Key

### gms
- GMS_KEY=GMS Key

### Rabbit MQ
- MQ_HOST=호스트
- MQ_PORT=포트
- MQ_USERNAME=유저 이름
- MQ_PASSWORD=유저 패스워드
- MQ_QUEUE_POSTER_CREATE=포스트 생성
- MQ_QUEUE_POSTER_EDIT=포스트 수정
- APP_SERVER_ID=서버 아이디

### Python
- PYTHON_URL=AI 파이썬 서버
