## 로고 생성
- 사용자가 입력한 프롬프트와 스타일을 기반으로 AI가 로고 이미지를 생성합니다.
- 생성된 로고는 서버에 저장되며, 이미지 URL과 로고 ID를 응답으로 반환합니다.
- 인증된 사용자만 이 API를 사용할 수 있으며, Bearer 토큰을 통해 인증을 진행합니다.

### **요청 URL**
| **구분** | **상세값** |
|------|------|
| **HTTP URL** | `https://j13d201.p.ssafy.io/api/logos` |
| **HTTP Method** | POST |

### 요청 헤더
| **구분** | **상세값** |
|------|------|
| **Authorization** | `[토큰 타입] [ACCESS_TOKEN]` <br> 토큰 타입은 Bearer로 고정 |
| **Content-Type** | `application/json` |

### 요청 쿼리 파라미터
| **이름** | **타입** |  **설명** |
|------|------|------|
| **style** | String | 로고 생성시 참고할 스타일 값 <br> `SIMPLE(깔끔한)`, `MONO(흑백)`, `PUNK(펑크)`, `CARTOON(만화)` |

### 요청 본문
| **이름** | **타입** |  **설명** |
|------|------|------|
| **prompt** | String | 로고를 생성할 프롬프트 <br> 예시: `네이비 색 배경의 우주선 로고 만들어줘` |
| **title** | String | 생성된 로고를 저장할 제목 |
| **content** | String | 생성된 로고를 저장할 내용 |

### 응답 본문
| **이름** | **타입** |  **설명** |
|------|------|------|
| **code** | String | 응답 코드 |
| **data** | 응답 데이터 객체 | 응답 데이터를 담은 객체 |
| **message** | String | 에러에 대한 메시지 |

#### 응답 데이터 객체(data)
| **이름** | **타입** |  **설명** |
|------|------|------|
| **logoId** | Long | 생성된 로고의 ID(PK) |
| **imgUrl** | String | 생성된 로고를 조회할 수 있는 URL |

#### 응답 코드
| **응답 코드** | **메시지** |
|------|------|
| **S0000** | 정상 처리 <br> (메시지는 따로 포함되지 않습니다.) | 
| **LG5001** | 로고 생성 서버 처리에 실패했습니다 |
| **LG5002** | 생성된 이미지가 비어있습니다 |
| **LG5003** | 유효한 이미지 포맷이 아닙니다 |
| **LG5004** | 이미지 용량이 제한을 초과했습니다 |
| **LG5005** | 로고 이미지 업로드에 실패했습니다 |
| **LG5006** | 프롬프트 정제에 실패했습니다 |
